# Smart Warehouse Grid Locator

## Project Overview
This Java project demonstrates a simple **Smart Warehouse Grid Locator** using **Object-Oriented Programming (OOP)** and a **2D array** to store and search warehouse items.

## Features
- Uses a `GridItem` class to represent each item
- Uses a `Warehouse` class to manage the grid
- Stores items at specific row and column positions
- Searches for an item by its ID
- Displays the warehouse layout with empty slots shown clearly

## Project Structure
- `SmartWarehouse.java` – Main program with `GridItem`, `Warehouse`, and `main()`

## How to Run
1. Open terminal in this folder
2. Compile the program:
   `javac SmartWarehouse.java`
3. Run the program:
   `java SmartWarehouse`

## Example Output
- The program displays the warehouse grid
- Searches for an item ID such as `I102`
- Shows `Item found at Row: 1, Column: 2` or `Item not found in warehouse`

## Learning Goals
- Understand 2D arrays in Java
- Apply OOP concepts such as classes and objects
- Practice searching through a grid using nested loops
- Build a simple real-world warehouse simulation
